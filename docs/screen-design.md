# 화면 설계

## 1. 방향

Waypoint MVP 화면은 반복적으로 보는 업무 콘솔이다. 장식적인 랜딩 페이지가 아니라, 운영자가 현재 상태와 확인 우선순위를 빠르게 읽는 밀도 있는 화면으로 구성한다.

MVP에서는 인증과 권한 구분을 만들지 않는다. 모든 화면은 단일 운영자 관점으로 설계한다.

## 2. 전체 구조

상단에는 서비스명, 기준 시각, 새로고침 버튼을 둔다.

첫 화면은 통합 대시보드로 구성한다. 운영자는 화면 이동 없이 운영현황, 이상징후, AI 브리핑을 같은 화면에서 확인한다.

대시보드 섹션:

- 운영현황 요약
- 이상징후 목록
- AI 브리핑 패널

공통 필터:

- 기준 일자
- 시간대
- 노선
- 상태

MVP에서는 복잡한 저장 필터나 사용자별 설정을 제공하지 않는다.

## 3. 운영현황 섹션

목적:

- 현재 어떤 노선이 정상, 주의, 이상 상태인지 빠르게 확인한다.

주요 구성:

- 요약 지표 영역
- 노선 상태 테이블
- 최근 수집 시각 표시

요약 지표:

- 전체 관찰 노선 수
- 정상 노선 수
- 주의 노선 수
- 이상 노선 수
- 위치 갱신 지연 노선 수

노선 상태 테이블 컬럼:

- 상태
- 노선번호
- 방향 또는 기종점
- 관측 차량 수
- 평균 차량 간격
- 최대 차량 간격
- 최근 위치 갱신
- 마지막 도착정보 수신

상태 표현:

- 정상: 기준 범위 내
- 주의: 임계값에 근접하거나 일부 데이터 지연
- 이상: 임계값 초과 또는 위치 갱신 지연

운영자 액션:

- 새로고침
- 노선 선택
- 상태 필터 변경
- 이상징후 목록으로 스크롤 또는 포커스 이동

## 4. 이상징후 섹션

목적:

- 계산된 이상징후를 우선순위 기준으로 확인한다.

주요 구성:

- 이상징후 목록
- 선택한 이상징후 상세 패널
- 근거 데이터 영역

목록 컬럼:

- 심각도
- 발생 시각
- 노선번호
- 유형
- 영향 구간 또는 정류소
- 근거 지표
- 최근 갱신 시각

이상징후 유형:

- 차량 간격 벌어짐
- 차량 간격 붙음
- 위치 갱신 지연

상세 패널:

- 탐지 사유
- 관련 차량 또는 정류소
- 계산에 사용한 기준값
- 최근 관측값
- AI 브리핑에 포함 여부

운영자 액션:

- 시간대 변경
- 노선별 필터
- 심각도별 필터
- AI 브리핑 생성 대상에 포함

## 5. AI 브리핑 섹션

목적:

- 서버가 계산한 이상징후를 운영자가 읽기 쉬운 문장으로 요약한다.

주요 구성:

- 브리핑 생성 버튼
- 브리핑 본문
- 브리핑 근거 목록
- 생성 이력

브리핑 생성 입력:

- 기준 시각
- 포함할 이상징후 목록
- 최대 요약 건수

브리핑 본문 구성:

- 전체 요약
- 우선 확인 노선
- 영향 구간
- 근거 지표
- 확인 필요 사항

브리핑 본문 원칙:

- 확정 원인을 단정하지 않는다.
- "가능성이 있습니다", "확인이 필요합니다"처럼 후보 표현을 사용한다.
- 서버 계산 결과에 없는 사실을 추가하지 않는다.

운영자 액션:

- 브리핑 생성
- 브리핑 다시 생성
- 근거 이상징후 확인
- 생성 이력 선택

## 6. MVP 제외 화면

다음 화면은 만들지 않는다.

- 로그인
- 사용자/권한 관리
- 민원 검증
- 자연어 검색
- 데이터 상태 전용 화면
- 도착 예정 시간 변동 분석 화면
- 관리자 설정
- 지도 기반 관제 화면
- 운영현황/이상징후/AI 브리핑 별도 탭 화면

## 7. 반응형 기준

MVP의 1차 대상은 데스크톱 브라우저다.

- 최소 권장 폭은 1280px이다.
- 모바일 전용 화면은 만들지 않는다.
- 좁은 화면에서는 테이블 가로 스크롤을 허용한다.
